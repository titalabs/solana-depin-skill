The Solana AI Kit just shipped — a production-ready Claude Code / Codex configuration that turns any coding agent into an expert Solana builder. It bundles specialized agents, workflow commands, MCP integrations, and a progressively-loaded skill hub that routes to the best skills across the ecosystem: Solana Foundation, SendAI, Colosseum, Helius, Jupiter, Metaplex, Trail of Bits, Cloudflare, and more.

To mark the release, we're opening the kit up to the community. We want new, useful, cross-domain AI skills that deserve a place in the standard kit — skills that genuinely help founders and engineers in their day-to-day, not toy demos.

The challenge
Build and submit a new Solana skill that solves a real, important problem for builders — ideally something nobody in the ecosystem has properly solved yet. Two valid paths:

Level up a seed skill — take one of the skills we've already scoped (below) from starting phase to production-grade via a PR.

Ship your own — submit your own repo with an entirely new skill solving a novel problem for Solana founders and builders.

What we care about is whether the skill is something people will actually reach for.

Seed ideas
We spotted three gaps nobody in Solana is properly solving yet and started seeding them. They're still in their starting phase — we welcome PRs to take them to the next level, and they double as inspiration for your own ideas:

crypto-legal-skill — Legal AI skills for crypto: from compliance and incorporation to local stablecoin regulations.

position-manager-skill — CLMM position manager for Orca Whirlpools / Raydium CLMM / Meteora DLMM: track impermanent loss, alert on out-of-range positions, and suggest rebalances.

solana-auditor-skill — Auditor-lifecycle skill: an all-in-one security expert, not just a quick code audit — formal verification, deep analysis, and full report generation.

These are a few ideas we came up with, not a limit. The best submissions may well be something we haven't thought of.

Reference skill
For structure, follow solana-game-skill — a clean, well-formed example of a kit skill:

a skill/ folder with a SKILL.md entry point that routes to focused .md skill files (progressive, token-efficient loading)

optional agents/, commands/, and rules/

an installer script and a clear README

Match that shape and your skill might slot straight into the kit. Favor clean, safe implementations: no shady executables, no bloating, nothing opaque or unnecessary.

What makes a great submission
Solves a real, recurring problem builders hit — cross-domain is a plus

Production-grade, not AI slop: tested, accurate, and current to the 2026 stack

Progressive / token-efficient — loads context only when it's needed

Clear SKILL.md routing, good docs, and a working install path

MIT licensed and ready to be merged or submoduled into the kit

You can also build agents/commands/configs specific to the main use cases of your skill, but this is not required

Submission requirements
A public GitHub repo/ PR link containing your skill

A README explaining what it does, the problem it solves, and how to install it

A comprehensive SKILL.md / entry point following the kit's structure

Submit the PR link + questionnaire on this listing

if you're building a novel skill please also submit it as PR here https://github.com/solanabr/skill-bounty


Judging criteria
Usefulness — does this solve a real problem builders face?

Novelty — is it filling a genuine gap in the ecosystem?

Quality — production-grade, accurate, tested, well-documented?

Fit — does it slot cleanly into the standard kit?
